How to choose

まず、目的に近いプラグインを選ぶ

プラグインは導入単位です。その中に、具体的な作業を導く複数の SKILL が入っています。下の表で、対象領域と含まれる SKILL をまとめて確認できます。

  1. 目的を選ぶ設計、iOS、グラフ、GitHub、文章から探す
  2. プラグインを追加するCodex の「個人用」から導入
  3. SKILL を呼び出す新しいタスクで依頼する

Get started

画面で追加するcodex plugin add <plugin-name>@personal

Boundary

プラグインが行うこと、行わないこと

プラグインは判断の規範と手順を提供します。GitHub への push、PR 作成、認証などの外部変更は、利用者からの明示的な依頼がある場合にだけ実行します。
