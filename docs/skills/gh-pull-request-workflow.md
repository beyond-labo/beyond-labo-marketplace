# GitHub Pull Request Workflow

選択した変更をコミット・pushし、GitHub CLIで PR を作成または確認するときに使います。

PR はデフォルトでドラフトにし、本文には実行済みの検証だけを記載します。

タイトルと本文は、利用者が指定した言語で作成します。

指定がない場合は、依頼文とリポジトリの利用者向けドキュメントの主言語に合わせます。

## 前提条件

- `gh auth status` が成功すること
- コミット・push・PR 作成を利用者が明示的に依頼していること

## プロンプト例

```text
この機能追加に関係する変更だけを確認してコミットし、ブランチをpushして日本語本文のドラフトPRを作成してください。
```
