## Beyond Labo の変更

- `skills/unslop/SKILL.md`：フロントマターをこのリポジトリの形式に揃え、作者とライセンスは本文にも表示した。Web と iOS の分岐、監査のみの扱い、日本語での報告、既存の許可とブランドの保持を追加した。一律の確認待ちと描画回数上限を置き換え、画像からの再構築を実装依頼の範囲に限定した。
- `skills/unslop/agents/openai.yaml`：日本語の表示とプロンプトを設定した。初期運用は明示呼び出し専用とした。
- `skills/unslop/references/ios.md`：Web 固有の規則より優先するネイティブ UI の改善手順と検証条件を追加した。
- `skills/unslop/references/web-runtime.md`：同梱スクリプトの実行場所、任意の依存、出力と制約を追加した。
- `.codex-plugin/plugin.json`：Codex の配布メタデータを追加した。
- `NOTICE.md`、この文書、`UPSTREAM-FILES.json`：帰属、変更、更新の追跡情報を追加した。
- `LICENSE`：リポジトリの空白検査に合わせ、ファイル末尾の余分な空行だけを除去した。ライセンス本文は変更していない。

上流のスクリプト、テスト、examples、画像、既存の references は変更していない。
既存の各ファイル内の作者表示も保持している。
Beyond Labo の追加分を含め、このプラグインは CC BY 4.0 で配布する。

## 更新するとき

1. 上流を別の作業コピーへ取得し、候補コミットを固定する。
2. 現在の固定コミットと候補の差分を調べ、ライセンス、作者表示、参照画像の出典、依存、スクリプトの入出力を確認する。
3. 上流の変更を取り込み、この文書に記録した独自変更を再適用する。インストール済みキャッシュは編集しない。
4. `UPSTREAM-FILES.json` のコミット、対象ファイル一覧、上流ハッシュ、変更有無を取得したソースに合わせて更新する。削除されたファイルを残さず、過去の変更表示と帰属は保持する。
5. プラグインの版番号を更新し、カタログ、README、公開ガイドの名前、版番号、前提条件を照合する。版番号と上流コミットを混同しない。
6. skill validator、利用できる plugin validator、参照リンク、上流テストを確認する。ブラウザーや ffmpeg がない場合の skip と実行失敗を区別し、未実施の機能を成功と記録しない。

上流 `main` の自動追従や利用プロジェクトへの自動インストールは行わない。
配布ブランチへの取り込み後にマーケットプレイスを更新し、プラグインの更新状態を確認して新しいチャットで利用する。
