# japanese-tech-writing

日本語の技術文書、書籍原稿、解説記事を執筆または推敲するときに使う SKILL です。

一文一行の整形、段落単位の論証、用語の一貫性、読者の負荷、冗長な表現を点検します。

## いつ使うか

技術的な内容を日本語で説明する原稿を新しく書くとき、または既存の原稿の論理や表現を整えるときに使います。

文体だけでなく、根拠のない断定、因果の飛躍、曖昧な否定も確認したい場合に向きます。

## 前提条件

入力となる原稿、または説明したい技術的な事実を用意します。

事実確認が必要な箇所は、確認済みの資料や根拠もあわせて渡します。

## プロンプト例

```text
$japanese-tech-writing
以下の設計解説を、日本語の技術記事として推敲してください。
一文一行の形式を守り、論理の飛躍と曖昧な因果を指摘したうえで修正案を示してください。

（原稿を貼り付ける）
```
