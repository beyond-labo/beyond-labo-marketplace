How to choose

まず、目的に近いプラグインを選ぶ

プラグインは導入単位です。その中に、具体的な作業を導く複数の SKILL が入っています。下の表で、対象領域と含まれる SKILL をまとめて確認できます。

  1. 目的を選ぶ仕様・知識更新、設計、グラフ、GitHub、文章から探す
  2. プラグインを追加するCodex の「個人用」から導入
  3. SKILL を呼び出す新しいタスクで依頼する

Get started

導入は一度だけ

マーケットプレイスを Codex に追加したら、「個人用」タブから必要なプラグインを選べます。

画面で追加するcodex plugin add <plugin-name>@personal

SKILL は、依頼の組み立て方と出力の判断基準を Codex に与えます。目的に合う名前を使って呼び出してください。

OKF + SDDkiro-debug.kiro の仕様駆動開発で、実装・検証失敗の原因を調べ、根拠のある修正と再検証を決める。原因不明の失敗や繰り返すレビュー指摘に使う。開く
kiro-discovery.kiro の仕様駆動開発で、新規・既存仕様・直接実装への振り分けと brief / roadmap を作る。方針やコードの一般的な調査だけには使わない。開く
kiro-impl.kiro の仕様駆動開発で、承認済み仕様のタスクを実装・検証し、実装で得た知見を現行仕様へ同期する。タスク指定時はその範囲、未指定時は未完了タスクを扱う。開く
kiro-review.kiro の仕様駆動開発で、実装差分を現行の承認済み仕様・責務境界・検証証拠に照らしてレビューする。実装後、修正後、タスク受け入れ時に使う。開く
kiro-spec-batch.kiro の roadmap にある複数仕様を依存順に生成・更新する。仕様間レビューと共有索引の更新を統括する。開く
kiro-spec-design.kiro の承認済み要件を設計文書と調査記録へ具体化し、工程の生成・承認状態を扱う。一般的なアーキテクチャ設計のみには使わない。開く
kiro-spec-init.kiro に新しい機能仕様の制御 JSON と要件の雛形を作る。既存仕様の更新には sync を使う。開く
kiro-spec-quick単一の .kiro 仕様の要件・設計・タスクを必要な段階から連続生成する。--auto または既存の一括許可の範囲で承認を反映する。開く
kiro-spec-requirements.kiro の機能仕様の要件と受け入れ条件を生成・更新する。一般的な文章推敲には使わない。開く
kiro-spec-status.kiro の仕様駆動開発で、仕様の生成、承認、実装進捗と文書の同期状態を読み取り専用で確認する。開く
kiro-spec-sync.kiro の仕様駆動開発で、要件、設計、実装、方針の変更を関連文書へ反映し、古い承認と完了状態を再評価する。文書の矛盾発見、仕様変更、実装完了時に使う。--check は読み取り専用の整合性点検。開く
kiro-spec-tasks.kiro の要件と設計から、依存関係と検証条件を持つ実装タスクを生成・更新する。開く
kiro-steering.kiro の仕様駆動開発で、コードと決定の根拠をもとに、プロジェクト方針を作成または更新する。古い方針の置換と関連仕様への影響確認を含む。開く
kiro-steering-custom.kiro の仕様駆動開発で、API、テスト、セキュリティなど特定領域のプロジェクト方針を作成または更新する。開く
kiro-validate-design.kiro の仕様駆動開発で、要件、関連仕様、実装上の根拠と設計を照合し、実装へ進める品質かをレビューする。開く
kiro-validate-gap.kiro の仕様駆動開発で、現行の要件と既存コードの差分を調べ、実装方針を選ぶための根拠を記録する。開く
kiro-validate-impl.kiro の仕様駆動開発で、実装後の機能について要件充足・設計整合・タスク間統合と検証証拠を確認する。対象タスク指定時は範囲を限定する。開く
kiro-verify-completion.kiro の仕様駆動開発で、タスク完了、修正成功、検証成功、機能 GO の主張を対象状態に対応する証拠と照合する。開く

図とグラフの使い分け

図の生成は Archify、コードと文書の知識探索は Graphify、コードの呼び出し関係と変更影響は CodeGraph を使います。

Boundary

プラグインが行うこと、行わないこと

プラグインは判断の規範と手順を提供します。GitHub への push、PR 作成、認証などの外部変更は、利用者からの明示的な依頼がある場合にだけ実行します。
