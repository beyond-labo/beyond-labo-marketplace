# Git & GitHub CLI Authentication

`gh auth status` の失敗、期限切れ・無効なトークン、GitHub CLI へのサインインが必要な Git/GitHub 作業に使います。認証後は必ず `gh auth status` を再実行し、ローカル CLI に認証が保存されたことを確認します。

## 前提条件

- `gh` がインストールされていること
- デバイス認証を承認できる GitHub アカウントでブラウザにサインインできること
- デバイス認証中は、コードを発行した `gh auth login` プロセスを終了させないこと

## プロンプト例

```text
gh の認証状態を確認し、認証エラーなら SSH 公開鍵を変更せずにデバイス認証を進めてください。認証後に gh auth status で確認してください。
```

## 安全な扱い

デバイスコードは承認した利用者にだけ共有し、ファイル、コミット、PR 本文には残しません。個人アクセストークン、パスワード、MFA コードをチャットへ送らないでください。
