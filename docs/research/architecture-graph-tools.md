# アーキテクチャとグラフのツール構成

2026年9月9日に公式ソースと公開パッケージを確認し、3つの独立した `DeveloperTools` プラグインとして導入しました。
各プラグインは1つの SKILL とセットアップ参照を持ち、上流の CLI を利用します。
上流の実行環境は別途導入するため、プラグインの追加と依存のインストールは別の操作です。

## 対象の識別

| プラグイン | 公式リポジトリ | 確認したバージョン | 主な入力と出力 |
| --- | --- | --- | --- |
| [Archify](../plugins/archify.md) | [tt-a1i/archify](https://github.com/tt-a1i/archify) | 2.17.0-dev.1 | システムの説明やコードの根拠 → JSON と単体 HTML の図 |
| [Graphify](../plugins/graphify.md) | [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) | graphifyy 0.9.56 | コードと文書 → 知識グラフ、関係の検索、HTML とレポート |
| [CodeGraph](../plugins/codegraph.md) | [colbymchenry/codegraph](https://github.com/colbymchenry/codegraph) | @colbymchenry/codegraph 1.6.0 | ソースコード → シンボル、呼び出し関係、変更影響 |

Graphfy という依頼名は、指定された URL に従って Graphify としました。
CodeGraph には同名の実装がありますが、ここでは指定された scoped npm パッケージを対象にします。
Archify は開発版のため、実行方法とスキーマを同じコミットへ固定します。
各確認リビジョンはプラグイン内の `references/setup.md` に記録しています。

## 既存プラグインとの分担

既存の System Architecture Design は、境界や責務をどう設計するかを判断する規範です。
Archify は図という成果物を生成する実行ツールであり、設計レビューだけの依頼では選択しない description にしました。
Git & GitHub Workflow と対話・コミュニケーションには、この3ツールの実行環境やグラフ操作を移しません。

Graphify と CodeGraph はコード解析の一部が重なります。
通常の選択では、コードと文書の関係を Graphify、関数の呼び出しや変更影響を CodeGraph が担当します。
利用者がツールを指定した場合は、その指定を優先します。
両方のグラフを無条件に作る運用にはしません。

## 独立した導入単位にする理由

Archify は Node.js の図生成環境、Graphify は Python の知識抽出環境、CodeGraph はコード索引の実行環境を持ちます。
依存、更新頻度、生成物、外部 LLM の利用条件が異なり、1つだけでも利用できます。
このため既存の設計プラグインへの統合や、3ツールを一括導入するプラグインは採用しません。

共通するのは用途の選択基準であり、その正本をこの構成記録に置きます。
実行手順と依存情報は各 SKILL が所有し、他プラグインへの必須依存を持ちません。
公開ページはこの境界を説明し、実行時には各プラグイン単体で必要な参照を読めます。

## CLI と MCP の選択

3件とも今回の用途は CLI で実行できるため、MCP 接続設定を同梱しません。
Graphify と CodeGraph が上流で提供する MCP は、利用者が別途必要とする場合の選択肢です。
この構成ではサーバーの自動起動、ツールの自動許可、エージェント設定への登録を伴いません。

Graphify のコード解析と CodeGraph の解析に API キーは不要です。
Graphify の文書解析は、現在のアシスタントが抽出する方法と、明示的に選んだ LLM バックエンドを使う方法を案内します。
後者の認証と送信先はセットアップ参照に記載し、環境にキーがあるだけで送信を開始しない手順にしています。
CodeGraph の既定のテレメトリーは、この統合の実行時環境変数で無効にします。

## 上流と配布物の扱い

このリポジトリには、独自に記述した統合用 SKILL と公開ガイドを追加します。
上流ソース、バイナリ、ライセンス本文の複製は含めません。
上流のライセンスは各上流配布物に適用され、当リポジトリ全体の利用許諾を変更しません。
上流更新時は依存バージョン、コマンド、入出力、副作用を再確認し、SKILL と公開ガイドを同じ変更で更新します。

既存プラグインの移動や改名はなく、既存利用者の移行操作は不要です。
カタログの既存順序を維持し、Archify、Graphify、CodeGraph の順で末尾へ追加します。

## 導入時の検証

2026年9月9日、一時ディレクトリの小規模な入力で次を確認しました。
実行環境や生成物をマーケットプレイスへ同梱せず、既存の利用者環境への登録も行っていません。

| 対象 | 確認内容 | 結果 |
| --- | --- | --- |
| Archify | `doctor` と上流シーケンス例の `deliver --quality showcase` | HTML 生成成功、9/9 検証合格、エラーと警告は0 |
| Graphify | Python 3ファイルをコード抽出し、検索と `cluster-only --no-label` を実行 | 6ノード、9エッジを取得し、HTML とレポートを生成 |
| Graphify | 文書の記述を手動で抽出形式にし、コードのグラフと統合して検索 | 文書からコードへの出典付き関係を保持 |
| CodeGraph | Python 3ファイルを初期化し、状態、呼び出し元、変更影響を取得 | 8ノード、9エッジを取得し、関数間の関係を確認 |
| CodeGraph | テスト候補の命名フィルター | 既定では空、`--filter 'test_*.py'` 指定で対象テストを検出 |

これは固定した実行環境と小規模な入力の動作確認です。
全言語の抽出精度、大規模リポジトリ、クラウド LLM の認証後実行、Codex アプリからのインストール実行は未検証です。
Archify の HTML はレンダラーで検証し、ブラウザーでの視覚検査は行っていません。
