# Marketplace Updater SKILL

別の作業環境で見つかった問題を、マーケットプレイス配布元のプラグインや SKILL の改善へ反映します。

## いつ使うか

利用中のスキルに判断の抜けや矛盾が見つかり、今後の作業でも同じ問題が起きないようにスキル自体を直したいときに使います。
「この問題が起こらないように $skill-name で改善して」「スキル自体を直して」など、再発防止を求める依頼が対象です。
通常のスキル利用、成果物だけの修正、配布済みバージョンへの更新には使いません。

## 前提条件

[Marketplace Updater プラグイン](../plugins/marketplace-updater.md)と、対象のスキルを導入し、新しいタスクで使います。
別のプロジェクトを開いていても利用できます。
対象スキルのインストール情報を読み取れること、配布元へ接続できること、改善用の作業コピーへ書き込めることが必要です。
PR 作成には `gh` の認証と公開権限、検証には配布元が指定する実行環境を使います。

## プロンプト例

直前の会話から対象と問題を特定できる場合は、短い指示で進められます。
次の例では、推測を断定に変えてしまった問題が会話中にあることを想定しています。

```text
この問題が起こらないように、$japanese-tech-writing 自体を改善してほしい。
```

この依頼では配布元のソースを修正し、検証済みの差分を用意します。
公開まで任せる場合は、到達点を含めます。

```text
$marketplace-updater で、今回の問題が再発しないように $japanese-tech-writing の配布元を改善して、検証、コミット、push、ドラフトPR作成まで進めてください。
```

タスク中に見つかる問題を、その都度の再指示なしで改善する場合は、範囲を指定できます。

```text
このタスク中は、使用したマーケットプレイスのスキルに再発防止が必要な不備を見つけたら、Marketplace Updater で配布元の修正、検証、ドラフトPR作成まで進めてください。通常の成果物修正も続けてください。
```

継続許可は、このタスクと依頼された範囲に適用します。
他のタスクでも同じ運用をしたい場合は、そのタスクでも許可するか、利用者が管理する共通の指示へ明記します。

## 自動選択の範囲

`allow_implicit_invocation: true` により、Updater の名前を指定しなくても、対象スキル自体の改善依頼から選択できる設定です。
スキルの選択はモデルとタスクの文脈に依存するため、すべての言い回しでの発動を保証するものではありません。
明示的に実行したい場合は `$marketplace-updater` を指定します。

| 依頼や状況 | 扱い |
| --- | --- |
| 「同じ問題を防ぐため、スキル自体を直して」 | 配布元を確認して修正と検証を進める |
| 「$japanese-tech-writing でこの記事を改善して」 | 文章の修正を行う業務スキルを使う |
| スキル使用中に一度コマンドが失敗した | 原因を確認し、失敗だけを理由に配布元を変更しない |
| このタスク中のスキル改善と PR 作成が許可済み | 不備の根拠があるときに改善を続ける |
| 最新の配布元ですでに修正済み | 重複 PR を作らず、取り込み状況と更新方法を伝える |

## 入出力と保護する作業

入力は、実際に使われたスキル、問題が起きた状況、期待する振る舞いです。
会話にある情報を再入力する必要はありません。
同名のスキルや複数の配布元があり、対応を確定できない場合だけ確認します。

Updater はインストール済みキャッシュと配布元を区別し、ソースの作業コピーを修正します。
元の作業リポジトリのブランチと未コミット変更を保持します。
利用元のコードや秘密値は配布物へ持ち込まず、再現例には合成データを使います。

出力は、修正内容、検証結果、ベース SHA、作業コピーとブランチ、PR の URL または未公開の状態です。
認証や書き込み権限で止まった場合は、できた差分と残る操作を伝えます。
PR の作成、配布への取り込み、インストール済み版の更新状況を分けて報告します。

実行手順の正本は、配布元リポジトリの `plugins/marketplace-updater/skills/marketplace-updater/SKILL.md` です。
配布元をたどる詳細は、同じスキルの `references/source-resolution.md` にあります。
