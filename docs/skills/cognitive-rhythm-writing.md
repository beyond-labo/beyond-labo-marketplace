# cognitive-rhythm-writing

密度はあるが平坦に感じる説明文に、観察、逡巡、断定、再観察の認知モードの切り替えを設計する SKILL です。

状況を更新しない進行実況を削り、読者が読み進める理由を保つ文章へ推敲します。

## いつ使うか

技術記事、解説文、書籍の章などで、内容は正しいのに読後感が単調な原稿を見直すときに使います。

論証や表記自体の整合を優先する場合は、先に `japanese-tech-writing` を使います。

## 前提条件

入力となる原稿と、対象の事実、データ、場面、または主張の根拠を用意します。

この SKILL は根拠のない演出を足さず、原稿にある状況から緩急を作ります。

## プロンプト例

```text
$cognitive-rhythm-writing
以下の解説文は正確ですが、単調に感じます。
事実関係を変えず、認知の緩急を作るように推敲してください。
進行実況になっている文は削除または状況を更新する文に直してください。

（原稿を貼り付ける）
```
